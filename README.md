# JavaScript Projects 🚀  

This repository contains various JavaScript projects I built while learning JavaScript. These projects cover essential concepts like DOM manipulation and event handling.  

## 📂 Projects Overview  

Here are the projects included in this repository (as part of the course curriculum):  

1. **Digital Clock**  
   - **Description:** A real-time digital clock displaying the current time.  
   - **Tech Stack:** HTML, CSS, JavaScript (Date object, setInterval).  
   - **Folder:** [/Digital-Clock](https://github.com/rony-hassan/javaScript/tree/main/DIGITAL-CLOCK)  

2. **Stopwatch**  
   - **Description:** A functional stopwatch with start, stop, and reset capabilities.  
   - **Tech Stack:** JavaScript (setInterval, event handling), CSS.  
   - **Folder:** [/Stopwatch](https://github.com/rony-hassan/javaScript/tree/main/STOPWATCH)  

3. **Calculator**  
   - **Description:** A simple calculator for basic arithmetic operations.  
   - **Tech Stack:** JavaScript (event listeners, DOM manipulation), CSS.  
   - **Folder:** [/Calculator](https://github.com/rony-hassan/javaScript/tree/main/CALCULATOR)  

4. **Rock-Paper-Scissors Game**  
   - **Description:** Interactive game where the user plays against the computer.  
   - **Tech Stack:** JavaScript (randomization, event handling), CSS.  
   - **Folder:** [/Rock-Paper-Scissors](https://github.com/rony-hassan/javaScript/tree/main/ROCK-PAPER-SCISSOR)  

5. **Image Slider**  
   - **Description:** A dynamic image slider with navigation controls.  
   - **Tech Stack:** JavaScript (DOM manipulation, setInterval), CSS animations.  
   - **Folder:** [/Image-Slider](https://github.com/rony-hassan/javaScript/tree/main/IMAGE-SLIDER)  

6. **Weather App**  
   - **Description:** Fetches and displays weather data using an API.  
   - **Tech Stack:** JavaScript (Fetch API, async/await), CSS.  
   - **Folder:** [/Weather-App](https://github.com/rony-hassan/javaScript/tree/main/Weather%20Project) 

7. **TO-DO App**  
   - **Description:** A simple TO-DO list app for adding, deleting, and managing tasks.  
   - **Tech Stack:** JavaScript (local storage, event handling), CSS.  
   - **Folder:** [/TO-DO](https://github.com/rony-hassan/javaScript/tree/main/TO-DO)  

## 🎯 Concepts Covered

- **Mouse Events** – Handling click, hover, and other mouse interactions.
